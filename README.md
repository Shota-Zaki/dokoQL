# SQL Practice Lab

ブラウザ上でSQLを書き、実行結果とテーブル内容を確認しながら学習するための静的Webアプリです。GitHub Pagesだけで動作し、SQLはブラウザ内のPostgreSQL互換エンジンで実行します。

## 収録範囲

- 銀行口座を題材にしたSQL演習: 75問
- 商店を題材にしたSQL演習: 70問
- RPGを題材にしたSQL演習: 70問
- 正規化演習: 16問
- 予約管理データベースの総合設計演習

公開リポジトリでは、学習目的と条件を保ちながら問題文を再構成しています。初期データも演習条件を満たす学習用データとして再構成しており、外部サービスの非公開データは保存していません。

## 主な機能

- 問題一覧、Chapter、回答状態による絞り込み
- SQLエディタ
- SELECT / INSERT / UPDATE / DELETE / DDLのブラウザ内実行
- テーブルデータとテーブル定義の確認
- 問題開始状態へのDB初期化
- 実行結果を利用した自動判定
- ヒント、独自作成の解答例、考え方の表示
- 入力中SQL、正誤、回答回数、見直し状態のローカル保存
- PCの3ペイン表示
- タブレットの2ペイン+DBドロワー表示
- スマートフォンのタブ切替表示

## ローカル確認

ES Modulesを使用しているため、HTMLファイルを直接開くのではなくHTTPサーバー経由で確認します。

```bash
python -m http.server 4173
```

その後、ブラウザで `http://localhost:4173/` を開きます。

## 検査

Node.js 22以降で次を実行します。

```bash
npm run check
```

問題数、ID重複、必須フィールドとJavaScript構文を検査します。

## デプロイ

`work` または `main` へのpushで静的ファイルをGitHub Pagesへデプロイするワークフローを用意しています。

GitHub側でPagesのSourceを **GitHub Actions** に設定してください。設定後はワークフローが最新版を公開します。

## 学習データについて

- SQL実行環境はブラウザ内に閉じています。
- SQLを外部サーバーへ送信しません。
- 学習進捗はブラウザのLocal Storageへ保存します。
- 「DB初期化」は現在の問題用データを初期状態へ戻します。
- 解答例は公開済みの公式解答を転載したものではなく、各設問の条件から独自に作成した例です。
- 同じ結果を得る妥当な別解を許容できるよう、SELECTは原則として実行結果で判定します。

## 現在の制約

- 初期データは演習用の再構成データであり、外部環境のデータと完全一致することを目的としていません。
- 正規化などの記述式問題は自動判定せず、解答例との比較で学習します。
- トランザクションを継続したまま次の設問へ進む形式は、問題ごとの安全なDB初期化を優先して記述式として扱います。
